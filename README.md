# music-store-sql-analysis
A complete MySQL e-commerce database for a music store with 11 tables, sample data, and 10 analytical queries for learning SQL and database design.
📋 Overview

This repository contains a complete MySQL database setup for managing a music store with features including:

Artist & Album Management: Organize music by artist, album, and genre
Track Inventory: Store track metadata including duration, file size, and pricing
Customer & Sales: Track customers, invoices, and sales transactions
Playlist Management: Create and manage music playlists
Employee Hierarchy: Manage staff with reporting relationships
Business Intelligence: Pre-built queries for sales analytics and reporting

📋 Table Definitions
GENRE

Stores music genre categories (Rock, Jazz, Metal, Pop, etc.)

sql
- GenreId (PK)
- Name (VARCHAR 120)
ARTIST

Contains artist information

sql
- ArtistId (PK)
- Name (VARCHAR 120)
ALBUM

Albums linked to artists

sql
- AlbumId (PK)
- Title (VARCHAR 160)
- ArtistId (FK → ARTIST)
TRACK

Individual tracks/songs with pricing

sql
- TrackId (PK)
- Name (VARCHAR 200)
- AlbumId (FK → ALBUM)
- MediaTypeId (FK → MEDIA_TYPE)
- GenreId (FK → GENRE)
- Composer (VARCHAR 220)
- Milliseconds (INT)
- Bytes (INT)
- UnitPrice (DECIMAL 10,2)
MEDIA_TYPE

Audio/video file formats

sql
- MediaTypeId (PK)
- Name (VARCHAR 120) [MPEG, AAC, Protected AAC, etc.]
PLAYLIST

User-created music playlists

sql
- PlaylistId (PK)
- Name (VARCHAR 120)
PLAYLIST_TRACK

Junction table for tracks in playlists

sql
- PlaylistId (PK, FK → PLAYLIST)
- TrackId (PK, FK → TRACK)
EMPLOYEE

Store staff with hierarchical reporting

sql
- EmployeeId (PK)
- LastName, FirstName (VARCHAR)
- Title (VARCHAR 30)
- ReportsTo (FK → EMPLOYEE - self-referencing)
- BirthDate, HireDate (DATETIME)
- Address, City, State, Country, PostalCode
- Phone, Fax, Email
CUSTOMER

Customer information and support assignment

sql
- CustomerId (PK)
- FirstName, LastName (VARCHAR)
- Company (VARCHAR 80)
- Address, City, State, Country, PostalCode
- Phone, Fax, Email
- SupportRepId (FK → EMPLOYEE)
INVOICE

Sales transactions

sql
- InvoiceId (PK)
- CustomerId (FK → CUSTOMER)
- InvoiceDate (DATETIME)
- BillingAddress, BillingCity, BillingState, BillingCountry, BillingPostalCode
- Total (DECIMAL 10,2)
INVOICE_LINE

Line items in each invoice

sql
- InvoiceLineId (PK)
- InvoiceId (FK → INVOICE)
- TrackId (FK → TRACK)
- UnitPrice (DECIMAL 10,2)
- Quantity (INT)

🐛 Common Queries Reference

Find all tracks by a specific artist:

sql
SELECT t.Name, al.Title, g.Name 
FROM track t
JOIN album al ON t.AlbumId = al.AlbumId
JOIN artist a ON al.ArtistId = a.ArtistId
WHERE a.Name = 'AC/DC';

Calculate total spent per customer:

sql
SELECT c.FirstName, c.LastName, SUM(i.Total) as total_spent
FROM customer c
JOIN invoice i ON c.CustomerId = i.CustomerId
GROUP BY c.CustomerId;

Find most popular genre:

sql
SELECT g.Name, COUNT(*) as popularity
FROM genre g
JOIN track t ON g.GenreId = t.GenreId
GROUP BY g.GenreId
ORDER BY popularity DESC
LIMIT 1;
